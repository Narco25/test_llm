Project Highlights

The Astro portfolio site is a fast and focused personal website. It uses Astro for the frontend and Tailwind CSS for responsive styling.

The custom FastAPI LLM backend is a Python service that exposes a health endpoint and a text generation endpoint. It uses PyTorch for the custom model architecture and Uvicorn to run the server.

Security is part of the development process. The projects use strict CSP headers and XSS-safe text rendering. User text is treated as data and is not inserted as unsafe HTML.
